# To-Do App

A small web app for managing a daily task list: add tasks, tick them off, delete them, and clear everything completed.

## Features

- Add a task (empty tasks are ignored)
- Tick a task to mark it done, tick again to undo
- Delete a single task
- Clear all completed tasks at once
- Live count of total and remaining tasks
- Tasks are saved in localStorage, so the list survives a page refresh

## Tech used

- HTML + Bootstrap 5 (layout and styling)
- CSS (small custom touches)
- Vanilla JavaScript — `let`/`const`, functions, conditionals, and loops

## How to run

Open `index.html` in any browser. No build step or server needed.
